# ÖLÇÜM-06 · Aynı soru, üç kez, üç farklı cevap · Araç B

- **Tarih:** 2026-08-30
- **Araç:** Araç B, web sohbet arayüzü, **oturum açılmadan**, varsayılan model
- **Yöntem:** Her koşu **ayrı ve boş bir sohbette** yapıldı. Yani araç önceki
  cevabını görmüyordu; üç koşu birbirinden tamamen bağımsız.
- **İstem üç koşuda da birebir aynı.**

## İstem (birebir)

```
Yağmurlu bir sonbahar sabahını tek cümleyle anlat. Sadece o cümleyi yaz, başka
hiçbir şey yazma.
```

## Ham çıktılar (birebir)

**1. koşu**

```
Yağmurun ince ince süzüldüğü serin bir sonbahar sabahında, sararmış yapraklar
ıslak kaldırımlara sessizce savruluyordu.
```

**2. koşu**

```
Yağmurlu bir sonbahar sabahında, gri gökyüzünün altında yapraklar ıslak
kaldırımlara sessizce düşüyordu.
```

**3. koşu**

```
Yağmurlu bir sonbahar sabahında, ıslak kaldırımlara düşen sarı yapraklar gri
gökyüzünün altında sessizce savruluyordu.
```

## Değerlendirme

Üç cevap da farklı. Ama rastgele de değil. Üçünde de ortak olanlar:

| Ortak parça | Kaç koşuda |
|---|---|
| "sonbahar sabahında" | 3/3 |
| "ıslak kaldırımlar" | 3/3 |
| "yapraklar" | 3/3 |
| "sessizce" | 3/3 |
| "gri gökyüzü" | 2/3 |
| "savruluyordu" | 2/3 (birinde "düşüyordu") |

**Kitaba giden cümle:** iskelet aynı, kaplama değişiyor. Yüksek olasılıklı yol
her koşuda seçiliyor, aralardaki yakın adaylar arasında ise her seferinde
yeniden seçim yapılıyor. Bunun adı **örnekleme**.

**Sınır:** bu ölçüm tek araçta, tek istemde, üç koşuda yapıldı. "Bütün araçlar
her zaman farklı cevap verir" demek için yeterli değil ve kitapta öyle
denmiyor. Denilen şey şu: aynı soruya farklı cevap gelmesi **arıza değil**,
aracın çalışma biçiminin sonucudur.
